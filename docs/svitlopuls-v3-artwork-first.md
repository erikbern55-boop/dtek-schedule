Status: implementation plan for PR #43 only. NOT a production switch.

## Non-negotiable source of truth
The owner-approved neon reference image is the visual source of truth, not `svitlopuls-approved-preview.png` generated by CI. The separate two-garlic-bulb photograph supplied by the owner is the garden photo source. Do not substitute a stock image or a similar generated image.

## Architecture
1. Keep the original approved image as a reference asset, preserving its exact proportions. Build a CLEAN PLATE from it: remove ONLY baked-in changing numbers, dates, schedules, weather, garden text, lunar data, astrology and status text. Restore their panel backgrounds without disturbing frames, logo, photos, glow, decorations or dividers. A flat image with overlaid numbers is NOT acceptable while old numbers remain underneath.
2. Render a fixed-size 1404px-wide card using the clean plate as the base layer and position semantic HTML data layers in reference coordinates. Derive coordinates from the owner's image, not the current generated preview. Allow actual height to match the approved image's aspect ratio; do not crop to force 1536.
3. Reuse existing schedule/countdown/weather/garden/moon/astro data functions; do not hardcode the sample values in the approved screenshot. Keep link hit regions as real HTML anchors.
4. Preserve the existing responsive full-screen viewer's zoom/pan/rotation and automatic updates. Keep image scaling and HTML overlays in one transformed coordinate system.
5. Maintain both today's and tomorrow's data and emergency outage notifications. Keep Telegram bot and current Pages production rendering unchanged until explicit owner approval.

## Validation gates
- Visually compare the screenshot against the owner's approved image at the same resolution, including exact garden photo and all blocks.
- Test long/short real data strings, Ukrainian glyphs, wrapping, links, timer transitions, automatic reload, mobile portrait/landscape, and scrolling.
- Verify a live DTEK change reaches the V3 preview and that weather updates remain independent.
- CI success alone is NOT visual approval.
- No merge, deployment, Pages switch or Telegram publishing change without owner's explicit confirmation.

## Asset dependency
The approved screenshot and exact garlic photo must be committed as binary image assets to this test branch before implementation can be called faithful. This text-only plan does not claim those assets have been added.
