# Світлопульс 3.0 — погодний блок затвердженого еталона

**Статус:** погодний макет затверджено власником 14.11.2026. Тільки тестова гілка PR #43; **не публікувати** без окремого погодження.

## Еталон
- Затверджений виправлений PNG: `Світлопульс 3.0 - затверджений еталон - погода виправлена.png` у бібліотеці власника, папка `/Світлопульс 3.0/`.
- Фактичний розмір зображення: **1199 × 1312**. Не розтягувати до старого 1404 × 1536.
- Непорушні: заголовок, логотип, рамки, геометрія інших блоків, фото часнику, посилання, неонова стилістика.

## Погода сьогодні
- У межах **лише лівого погодного блоку** дата `DD.MM` безпосередньо після заголовка `Погода — СЬОГОДНІ`.
- Поточна температура розміщена вище попередньої позиції.
- Під нею окремі `Мін.`, `Макс.`, `Відчувається:` та стан погоди.
- Права колонка цього ж блоку: вітер, опади, тиск, вологість.
- Жоден напис не виходить за межі панелі й не перекриває «Завтра», «Світловий день» або інші панелі.
- Числа на еталоні — **ілюстративні**. У реальному рендері вони повинні надходити лише з погодного джерела; відсутні значення не підмінювати.

## Умови готовності
1. Потрібно додати саме затверджений PNG як бінарний файл у тестову гілку; GitHub текстовий API не підтримує бінарне завантаження через поточний конектор.
2. Підготувати clean plate без запечених динамічних цифр і дат; HTML-накладки не можуть дублювати текст на PNG.
3. Порівняти рендер 1199 × 1312 з еталоном; перевірити вузький портретний і горизонтальний перегляд.
4. Підключити перевірені DTEK JSON і реальну погоду, зберегти всі поточні функції.
5. Не зливати PR #43, не змінювати GitHub Pages або Telegram до затвердження власником.
